# SPEC 000: título da fatia

Modelo. Copie como `NNN-slug.md` (ex.: `001-oferta-relampago.md`). Uma spec é uma fatia que uma pessoa, ou uma sessão de IA, entrega em poucas horas.

- **Issue:** #
- **Requisitos do PRD:** F.., RNF..
- **Status:** Rascunho | Pronta | Feita

## Objetivo

Uma frase: o que passa a funcionar e para quem.

## Escopo

- **Dentro:** o que esta spec entrega.
- **Fora:** o que fica para outra spec ou para o backlog.

## Comportamento esperado

1. Dado [situação], quando [ação], então [resultado].
2. ...

## Dados e integrações

O que é real e o que é simulado, e onde ficam os dados simulados.

## Pronto quando

- [ ] Critérios de aceite acima funcionam na demonstração.
- [ ] Simulações aparecem identificadas na interface.
- [ ] SDD atualizado, se a spec mudou a arquitetura ou tomou uma decisão técnica.

## Dúvidas

Lacunas marcadas, nunca preenchidas por suposição.
